// FAQ //

IS THE MAIN APP REALLY FREE? ▶
Yes — the Ninja Dojo theme and all core features are completely free forever. The $5 bundle is purely for extra theme packs.
HOW DO I UNLOCK AFTER PAYING? ▶
After payment you'll see your unique code on screen and receive it by email. Enter it in the app under the theme selector to unlock all packs permanently on that device.
WHAT DEVICES DOES IT WORK ON? ▶
Any modern device with a microphone — iPad, iPhone, Android, laptop, or desktop. Works best propped up in landscape on an iPad or tablet.
DOES IT WORK WITHOUT INTERNET? ▶
Yes! Install it as a PWA (Add to Home Screen) and it runs fully offline. Perfect for classrooms with unreliable WiFi.
IS MY MICROPHONE DATA STORED? ▶
No. The app only measures volume levels in real-time — it never records or stores audio. Everything stays on your device.
CAN I USE MY CODE ON MULTIPLE DEVICES? ▶
Each code unlocks one device. If you need multiple devices contact support and we'll sort you out.
